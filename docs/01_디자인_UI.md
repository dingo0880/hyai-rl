# 01. 디자인 · UI 계획

## 1. 콘셉트

**"작은 콘서트홀 무대" + "그림책 같은 귀여움"**

어두운 무대에 스포트라이트가 떨어지고, 그 아래 피아노 건반 위에서 초파리가 콩콩 뛰며 연주한다. 오른쪽에는 초파리 머릿속을 들여다보는 창이 있다. 강의실 빔프로젝터로 봐도 잘 보이게, **크고 단순하고 대비가 강하게.**

## 3. 디자인 토큰

`:root`에 CSS 변수로 정의하고, 코드에서는 색을 직접 쓰지 않는다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--stage-bg` | `#141a2e` | 무대 배경 (어두운 남색) |
| `--stage-floor` | `#2a2140` | 무대 바닥 |
| `--spot` | `rgba(255, 236, 179, 0.35)` | 스포트라이트 |
| `--panel-bg` | `#1d2440` | 머릿속 패널, 하단 카드 |
| `--panel-line` | `#323a5c` | 카드 테두리 |
| `--text` | `#f5f1e8` | 기본 글자 |
| `--text-dim` | `#a9b0c8` | 보조 글자 |
| `--key-white` | `#fbf7ee` | 흰 건반 |
| `--key-black` | `#1b1b24` | 검은 건반 (장식) |
| `--key-edge` | `#2a2f45` | 건반 테두리 |
| `--correct` | `#ffc94a` | 정답, 설탕, 성장 지도 금색 |
| `--wrong` | `#ff5a5a` | 오답, 찌릿, 성장 지도 빨강 |
| `--dopamine-pos` | `#4ade80` | 도파민 + |
| `--dopamine-neg` | `#f87171` | 도파민 − |
| `--kc-off` | `#2c3456` | 꺼진 케년세포 |
| `--kc-on` | `#8ab4ff` | 켜진 케년세포 |
| `--accent` | `#c49bff` | 버튼, 강조 |
| `--accent-press` | `#a77ff0` | 버튼 누름 |

- 위 표 외에 초파리 캐릭터(`--fly-*`), 관객(`--face-*`, `--shirt-*`), 피아노 몸체(`--piano-case*`), 그래프(`--chart-grid`, `--cell-empty`, `--sparse`), 오버레이(`--overlay`, `--stage-dim`) 토큰을 추가했다. 값은 `css/style.css`의 `:root` 참고. 이 토큰들도 같은 규칙(코드에 색 직접 쓰지 않기)을 따른다.
- 라이트 테마는 만들지 않는다 (무대 콘셉트).
- **글꼴:** `"Malgun Gothic", "Apple SD Gothic Neo", "Noto Sans KR", sans-serif` — 설치된 시스템 글꼴만 사용, 외부 웹폰트 금지.
- **글자 크기 (1920 기준):** 제목 48px 굵게 / 본문 24px / 보조 18px / 건반 계이름 32px. `clamp()`로 1280에서 비율 축소.
- 모서리 16px, 그림자는 부드럽게 (`0 8px 24px rgba(0,0,0,.35)`).

## 4. 요소별 상세

### 4.1 헤더
- 왼쪽: 제목 "🪰 초파리 첫 피아노 연주회"
- 가운데~오른쪽: 연습 회차 카운터 "연습 37회차" (숫자가 바뀔 때 살짝 튀어 오르는 애니메이션)
- 오른쪽 아이콘 버튼: 정보(ⓘ), 소리 켜기/끄기(🔊/🔇), 전체화면(⛶)

### 4.2 악보 띠
- 42음을 한 줄로. 각 음은 둥근 칩에 계이름(도/레/미…). 소절 사이에 세로선.
- 2박짜리 음(각 소절 마지막)은 칩을 1.6배 넓게.
- 지금 칠 음: 크게 + 밝게 + 아래 작은 화살표.
- 지나간 음: 결과에 따라 **금색 ✓ / 빨강 ✗**로 칠해짐.
- 현재 음이 항상 띠 가운데쯤 오도록 부드럽게 옆으로 스크롤.

### 4.3 피아노
- 흰 건반 8개 (도 ~ 높은 도). 검은 건반은 **장식으로만** 그림 (누를 수 없음, 학습 대상 아님).
- 건반 아래쪽에 계이름 큰 글씨.
- 눌린 건반: 4px 내려감 + 정답이면 금빛 글로우, 오답이면 빨간 글로우 + 아이콘(✓/✗) 잠깐.
- 사람이 직접 클릭해서 칠 수도 있음 (소리 확인용, 학습에는 영향 없음).

### 4.4 초파리 캐릭터 (직접 그린 SVG)
- 생김새: 동글동글한 황토색 몸통, **크고 빨간 겹눈 2개**, 반투명 날개 2장, 다리 6개, 더듬이 2개. 눈을 크게, 몸을 둥글게 해서 귀엽게.
- 크기: 건반 하나 폭의 약 70%.
- 상태별 애니메이션:

| 상태 | 동작 | 길이 |
|---|---|---|
| 대기 | 날개 살랑, 더듬이 까딱 | 반복 |
| 이동 | 다음 건반으로 포물선 점프, 날갯짓 빨라짐 | 150ms |
| 정답 | 건반 위에서 깡총 + 머리 위 각설탕 반짝 | 300ms |
| 오답 | ⚡ 지지직 + 몸 떨림 + 눈이 잠깐 X자 | 300ms |
| 완주 | 앞다리 두 개 들고 꾸벅 인사 | 1s |
| 퇴장 (3번 실수) | 고개 숙이고 무대 옆으로 터덜터덜 | 1s |

- 표정은 눈 모양만 바꾸는 정도로 단순하게.

### 4.5 말풍선
- 초파리 머리 위. 둥근 말풍선, 글자 22px.
- 문구 목록과 뜨는 조건은 `02_기능.md` 7장.

### 4.6 관객석
- 무대 아래 한 줄, 단순한 동그란 얼굴 12~16개 (도형 + 표정).
- 반응:
  - 연주 중 오답이 많아지면 표정이 😐 → 😖
  - 0회 연주가 끝나면 몇 명이 귀를 막음
  - 완주하면 일어서서 위아래로 흔들리며 박수, 최고 등급이면 꽃이 날아옴

### 4.7 초파리 머릿속 패널
제목 "🧠 초파리 머릿속". 위에서 아래로 4칸.

1. **지금 보는 것 (상태)**: "3소절 · 2번째 박 · 방금 들린 음: 솔"
2. **케년세포**: 2,000개 중 200개를 20×10 점 격자로 표시. 이번 박에 켜진 세포는 파랗게 반짝. 캡션 "2,000개 중 약 100개만 켜져요".
3. **치고 싶은 건반 (가치)**: 건반 8개 모양 아래 막대. 양수 초록, 음수 빨강, 0은 가는 선. 고른 건반은 테두리 강조.
4. **도파민 (예측오차)**: 가운데 0을 기준으로 위(+, 초록) / 아래(−, 빨강)로 뻗는 큰 막대 하나. 아래에 "예상 0.2 → 실제 +1 → 놀람 +0.8".

- 패널 맨 아래 "📖 용어표" 토글 → 펼치면 `04_초파리_강화학습.md` 1장의 표를 그대로 보여줌.

### 4.8 하단 컨트롤
- 큰 버튼 5개 (높이 64px, 아이콘 + 글자): 연습 1회 / 연습 ×10 / 연습 ×100 / 연주회 열기 / 처음부터
- 무언가 진행 중이면 다른 버튼은 흐리게 비활성화.
- **연습 일지 칩 7개**: `0회 · 5회 · 15회 · 40회 · 80회 · 150회 · 300회`
  - 이미 지난 회차: 채워진 칩 (누르면 저장된 뇌로 바로 연주회)
  - 아직 안 간 회차: 테두리만 있는 칩 + ⏩ 아이콘 (누르면 그 회차까지 빨리 연습 후 연주회)
  - 칩에 마우스를 올리면 별명 표시 (예: "15회 · 첫 소절 성공")
- **🎬 성장 타임랩스** 버튼 (칩 오른쪽)

### 4.9 그래프 3개 (Canvas)
1. **학습 곡선**: x = 연습 회차, y = 그 회차에 끝까지 간 음 수 (0~42). 회차별 점 + 10회 이동평균 선. 스냅샷 회차에 작은 깃발.
2. **놀람(도파민) 곡선**: x = 연습 회차, y = 그 회차 평균 |도파민|. 점점 바닥으로 내려감. 제목 옆 설명 "잘할수록 놀랄 일이 줄어요".
3. **성장 지도**: 행 7개(스냅샷 회차) × 열 42개(음). 각 칸은 그 단계 연주회에서 그 음을 맞았으면 금색, 틀렸으면 빨강, 아직 안 들어본 단계는 회색. 행 왼쪽에 회차와 별명.
   - **이 그림이 "점점 잘하게 되는 과정"을 한 장으로 보여주는 핵심 시각화.** 금색이 왼쪽 위에서 오른쪽 아래로 번져간다.
   - 클릭하면 크게 확대 (발표 시나리오 5번에서 사용).

### 4.10 연주회 연출
1. 화면 전체가 살짝 어두워짐 (0.8초) → 스포트라이트가 초파리에게 (0.5초)
2. 가운데 큰 자막: "연주자: 초파리 · 연습 15회" (1.5초)
3. 연주 (악보 띠와 건반이 소리에 맞춰 움직임)
4. 결과 카드 (가운데 팝업): "42음 중 31음 정답 (74%)" + 별 1~5개 + 평론가 한줄평 + 관객 반응
5. 카드 닫기 → 평소 화면

### 4.11 성장 타임랩스 화면
- 7단계를 차례로 연주. 단계 사이에 자막 카드 "연습 40회 · 절반까지" (1초).
- 화면 위쪽에 진행 표시: ●●●○○○○
- 연주하는 동안 성장 지도의 해당 행이 실시간으로 칠해짐.

### 4.12 정보(ⓘ) 창
- 이 데모가 뭔지 3줄 설명
- "실제 초파리 뇌 전체가 아니라, 버섯체의 학습 구조를 본뜬 작은 모델이에요"
- 실제 초파리와 대응 (PN, 케년세포, MBON, 도파민 뉴런) + 다른 점 (`04` 문서 2.5)

### 4.13 (선택, Phase 6) 대치동 vs 산골 비교 화면
- 무대를 좌우로 나눠 초파리 두 마리 (왼쪽: 안경 쓴 대치동 초파리, 오른쪽: 밀짚모자 쓴 산골 초파리)
- 학습 곡선 하나에 선 두 개 (색으로 구분 + 범례)

## 5. 접근성 · 가독성

- 색만으로 구분하지 않기: 정답 ✓, 오답 ✗ 아이콘을 항상 같이.
- 글자와 배경 대비 충분히 (본문 4.5:1 이상).
- `prefers-reduced-motion`이면 점프·흔들림 애니메이션을 짧게.
- 빔프로젝터에서 흐려지는 얇은 선(1px) 대신 2px 이상.
