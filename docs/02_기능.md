# 02. 기능 계획

## 1. 모드 한눈에 보기

## 2. 연습(에피소드) 규칙

- 곡 처음부터 시작.
- 매 음: 초파리가 건반 선택 → 맞으면 **+1 (설탕)** / 틀리면 **−1 (찌릿)** → 학습 → 다음 음으로 넘어감 (틀려도 다음 음으로).
- **실수 3번이면 퇴장** (에피소드 종료, 관객 야유).
- 42음 끝까지 가면 **완주** (박수).
- 이 규칙 덕분에 처음엔 앞부분만 연습하고, 실력이 늘수록 점점 뒤까지 간다.
- 연주회에서는 실수 제한이 없다 (곡 전체를 들려주기 위해).
- 세부 수식은 `04_초파리_강화학습.md`.

---

## 3. 상태 흐름 (state machine)

```
idle ──[연습 1회]──▶ practicingLive ──끝──▶ idle
idle ──[×10 / ×100]──▶ practicingFast ──끝──▶ idle
idle ──[연주회 / 칩]──▶ concertIntro ─▶ concertPlaying ─▶ concertResult ──닫기──▶ idle
idle ──[타임랩스]──▶ timelapse(단계 1..7) ──끝──▶ idle
idle ──[처음부터]──▶ (확인창) ──▶ reset ──▶ idle
발표 모드: presentation(step k) — 각 step이 위 흐름을 순서대로 호출
```

- 무언가 진행 중이면 다른 버튼은 비활성화. 단 **ESC = 중단** (안전하게 idle로 복귀).
- 라이브 연습을 ESC로 중단해도 학습 결과는 이미 계산된 그대로 유지 (재현성 깨지지 않게, 아래 4장 참고).

---

## 4. 데이터 흐름

- `trainer`(강화학습)는 **순수 계산**만 한다. UI를 모른다.
- `trainer.runEpisode({ onStep })`가 매 음마다 이벤트를 내보낸다:

```js
{
  episode, t,                // 연습 회차, 몇 번째 음 (0~41)
  obs: { phrase, beat, prevNote },
  activeKCs,                 // 켜진 케년세포 인덱스 (Int32Array, 100개)
  values,                    // 8개 건반 예상 보상
  action, target,            // 고른 건반, 정답 건반
  reward,                    // +1 / -1
  prediction,                // values[action]
  dopamine,                  // reward - prediction
  mistakes, done
}
```

- **라이브 연습:** 에피소드를 한 번에 계산해서 이벤트를 큐에 쌓고, UI가 박자에 맞춰 하나씩 꺼내 재생한다. (계산은 즉시, 보여주기는 천천히)
- 이벤트 버스(`js/core/events.js`): `emit('step', data)`, `'episodeEnd'`, `'snapshot'`, `'concertEnd'`, `'timelapseStage'`.
- **중요:** 같은 시드면 ×1로 하든 ×100으로 하든 학습 결과가 완전히 같아야 한다. UI는 학습용 RNG를 건드리지 않는다.
- 기록(`trainer.history`): 회차마다 `{ reached, accuracy, meanAbsDelta }` → 학습 곡선·놀람 곡선에 사용.
- 연주회 결과 기록: 스냅샷 회차별 42음 정답 여부 배열 → 성장 지도에 사용.

## 5. 연습 일지 (스냅샷)

- 기본 스냅샷 회차: **0, 5, 15, 40, 80, 150, 300** (`04` 문서와 동일. 시뮬 결과에 맞춰 바꾸면 여기도 같이 바꾼다.)
- 학습 중 해당 회차에 도달하면 뇌 가중치(`W`) 복사본을 저장.
- 칩 이름:

| 회차 | 별명 |
|---|---|
| 0 | 갓 태어난 초파리 |
| 5 | 건반이 뭔지 앎 |
| 15 | 첫 소절 성공 |
| 40 | 절반까지 |
| 80 | 끝까지는 감 |
| 150 | 거의 완벽 |
| 300 | 초파리 마에스트로 |

- **이미 지난 칩:** 저장된 뇌로 바로 연주회.
- **아직 안 간 칩:** 그 회차까지 빨리 연습 → 연주회 (자동 빨리감기). 학습은 결정적이므로 라이브로 거기까지 간 것과 똑같은 뇌가 된다.
- **연주회 재현성:** 스냅샷마다 연주용 시드를 고정 (`concertSeed = 1000 + 회차`). 같은 칩은 몇 번을 눌러도 같은 연주.
- 연주회가 끝나면 그 결과(42음 정답 여부)를 성장 지도 해당 행에 저장.

## 6. 연주회

### 6.1 흐름
1. 조명 다운 (0.8초) → 스포트라이트 (0.5초)
2. 자막 "연주자: 초파리 · 연습 N회" (1.5초)
3. 연주: 100BPM, 42음 (각 소절 마지막 음은 2박) — 약 29초
4. 결과 카드: 점수 + 별 + 평론가 한줄평 + 관객 반응

### 6.2 결과 등급

| 정답률 | 별 | 관객 반응 | 평론가 한줄평 (랜덤 하나) |
|---|---|---|---|
| 0 ~ 30% | ★ | 귀 막기, 웅성웅성 | "현대음악인 줄 알았습니다" / "피아노가 불쌍합니다" / "곡 제목을 맞히는 퀴즈인가요?" |
| 30 ~ 60% | ★★ | 갸우뚱 | "앞부분은 분명 그 노래였다" / "후반부에 길을 잃은 듯" |
| 60 ~ 85% | ★★★ | 박수 조금 | "삑사리마저 개성으로 느껴진다" / "다리 6개의 한계를 넘어서고 있다" |
| 85 ~ 97% | ★★★★ | 큰 박수 | "곤충계의 신동 등장" / "실수 한두 번은 애교" |
| 97 ~ 100% | ★★★★★ | 기립박수 + 꽃 | "모차르트가 이 곡으로 변주곡을 쓴 이유를 알겠다" / "이 초파리, 음대 보내야 합니다" |

## 7. 말풍선 문구

| 상황 | 문구 (랜덤) |
|---|---|
| 오답 | "삑사리!" / "어… 이게 아닌데" / "건반이 너무 커요" / "다리가 6개라 헷갈려요" / "찌릿했다…" |
| 정답 5연속 | "오, 좀 치는데?" / "다리가 기억해요" / "이 노래 아는 것 같아요" |
| 퇴장 | "다음엔 잘할게요…" / "연습 더 하고 올게요" |
| 완주 | "감사합니다! 🎵" / "앙코르 받습니다" |
| 연습 0회 첫 연주 시작 | "피아노가 뭐예요?" |

- 너무 자주 뜨지 않게 **최소 2초 간격**, 최대 1.5초 표시.
- 빨리 연습 중에는 말풍선 없음.

## 8. 성장 타임랩스

- 버튼 하나로 7단계 연주회를 차례로 자동 재생.
- 단계 사이에 자막 카드 "연습 40회 · 절반까지" (1초).
- 두 가지 길이 옵션 (설정 패널):
  - **전곡 2배속** (200BPM, 단계당 약 15초 + 자막 1초, 총 약 2분) — 기본
  - **앞뒤 1소절씩 2배속** (첫 소절 + 마지막 소절만, 단계당 약 5초 + 자막 1초, 총 약 40초) — 발표 시간이 짧을 때.
    - 첫 소절만 들려주면 15회 이후로는 다 맞아서 차이가 안 들리므로, 마지막 소절을 꼭 이어 붙인다. 초반 단계는 마지막 소절이 엉망, 후반 단계는 둘 다 깔끔.
- 아직 안 간 단계는 자동으로 빨리 연습해서 채운다.
- 재생하면서 성장 지도의 해당 행이 실시간으로 칠해진다.
- ESC로 언제든 중단.

## 9. 발표 모드 (단축키 `P`)

`계획서.md` 2장 시나리오를 단계별로 진행. 각 단계가 끝나면 멈추고, 발표자가 **→ 키**를 누르면 다음 단계로 (말할 시간 확보).

| 단계 | 동작 |
|---|---|
| 1 | 초기화(시드 고정) + 소개 자막 "오늘의 연주자: 초파리 (연습 0회)" |
| 2 | 0회 연주회 |
| 3 | 라이브 연습 1회 (속도 70BPM으로 느리게, 머릿속 패널 테두리 강조) |
| 4 | 15회 연주회 (자동 빨리감기) |
| 5 | 성장 지도 + 학습 곡선 + 놀람 곡선 크게 보기 |
| 6 | 80회 연주회 → (→ 키) → 300회 연주회 |
| 7 | (선택, 설정에서 켰을 때만) 대치동 vs 산골 비교 |

- 화면 구석에 "발표 모드 3 / 7" 작게 표시.
- `←` 키: 이전 단계 다시.
- `P` 다시 누르면 발표 모드 종료.

## 10. 단축키

| 키 | 동작 |
|---|---|
| `Space` | 연습 1회 |
| `1` ~ `7` | 연습 일지 칩 (0회 ~ 300회) |
| `C` | 연주회 열기 (현재 뇌) |
| `T` | 성장 타임랩스 |
| `G` | 성장 지도 크게 보기 |
| `F` | 전체화면 |
| `M` | 소리 끄기 / 켜기 |
| `P` | 발표 모드 시작 / 종료 |
| `→` / `←` | 발표 모드 다음 / 이전 단계 |
| `S` | 설정 패널 열기 |
| `ESC` | 진행 중인 것 중단, 팝업 닫기 |
| `R` | 처음부터 (확인창) |

화면 하단 구석에 `?` 버튼 → 단축키 목록 팝업.

## 11. 설정 패널 (발표자용, 단축키 `S`)

| 설정 | 기본값 | 범위 |
|---|---|---|
| 시드 | 42 | 정수 |
| 학습률 α | 0.3 | 0.1 ~ 0.5 |
| 결단력 β | 6 | 3 ~ 8 |
| 케년세포 수 | 2000 | 500 ~ 4000 |
| 켜지는 비율 | 5% | 2 ~ 10% |
| 실수 제한 | 3 | 1 ~ 10 |
| 라이브 연습 속도 | 100BPM | 60 ~ 140 |
| 연주회 실수 없는 모드 | 끔 | 켬/끔 |
| 타임랩스 길이 | 전곡 2배속 | 전곡 2배속 / 앞뒤 1소절씩 2배속 |
| 대치동 vs 산골 모드 표시 | 끔 | 켬/끔 |
| 정답 멜로디 듣기 (확인용) | 버튼 | — |

- 학습 관련 설정을 바꾸면 "처음부터"를 자동 실행 (확인창).
- 설정값만 `localStorage`에 저장. **반드시 `try/catch`로 감싸고**, 저장이 안 돼도 기본값으로 정상 동작.
