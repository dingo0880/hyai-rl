# 03. 사운드 계획

## 1. 원칙

- **음원 파일 없이 Web Audio API로 전부 합성.** 오프라인으로 돌아가고, 저작권 걱정도 없다.
- **첫 클릭 때 AudioContext 시작** (브라우저 자동재생 정책). 시작 전에는 화면에 "🔊 클릭해서 소리 켜기" 안내를 띄운다.
- **빨리 연습(×10 / ×100) 중에는 음악 무음.** 끝날 때 짧은 효과음 한 번만.
- **틀린 음은 그대로 틀리게 들린다** — 이게 이 데모의 가장 큰 웃음 포인트.
- 볼륨 버스 구조:

```
피아노 음 ──▶ music bus (0.9) ─┐
효과음   ──▶ sfx bus   (0.5) ──┼──▶ master (1.0) ──▶ 컴프레서 ──▶ 스피커
관객 소리 ──▶ crowd bus (0.6) ─┘
```

- 마지막에 `DynamicsCompressorNode`를 걸어서 박수 + 피아노가 겹쳐도 소리가 깨지지 않게.
- `M` 키로 master 음소거.

## 3. 악보 — 반짝반짝 작은 별 (계이름만, 가사 없음)

| 소절 | 음 (마지막 음은 2박) | 건반 번호 |
|---|---|---|
| 1 | 도 도 솔 솔 라 라 **솔** | 0 0 4 4 5 5 **4** |
| 2 | 파 파 미 미 레 레 **도** | 3 3 2 2 1 1 **0** |
| 3 | 솔 솔 파 파 미 미 **레** | 4 4 3 3 2 2 **1** |
| 4 | 솔 솔 파 파 미 미 **레** | 4 4 3 3 2 2 **1** |
| 5 | 도 도 솔 솔 라 라 **솔** | 0 0 4 4 5 5 **4** |
| 6 | 파 파 미 미 레 레 **도** | 3 3 2 2 1 1 **0** |

- 총 **42음**, 소절당 8박 → 전체 48박.
- 템포 **100BPM** (1박 = 0.6초) → 곡 길이 약 **28.8초**.
- 라이브 연습은 기본 100BPM, 설정에서 60 ~ 140BPM. 발표 모드 3단계는 70BPM.
- 성장 타임랩스 2배속은 200BPM.
- 멜로디 원곡은 18세기 프랑스 민요로 저작권이 끝났다. **한국어 가사는 넣지 않는다.**

## 4. 피아노 합성음

음 하나를 만드는 법:

```
사인파 4개 (배음)
  기본음 × 1  음량 1.00
  기본음 × 2  음량 0.50
  기본음 × 3  음량 0.25
  기본음 × 4  음량 0.12
    ↓ 합치기
로우패스 필터 (약 3,000Hz, 딱딱한 소리 줄이기)
    ↓
음량 엔벨로프
  어택 5ms (0 → 1)
  감쇠 exponential, 1박 음은 약 1.2초 / 2박 음은 약 1.8초에 걸쳐 0.001까지
    ↓
music bus
```

- 아주 살짝 랜덤 디튠 (±2 cents) → 덜 기계적으로.
- 다음 음과 살짝 겹쳐도 괜찮다 (실제 피아노도 여운이 남음).
- **틀린 음:** 그 건반 음이 그대로 나는 것만으로 충분히 웃기지만, 추가로 **−25 cents 디튠**을 줘서 "삑사리" 느낌을 강화한다. (설정에서 끌 수 있게)
- 동시 발음 최대 8개. 넘으면 가장 오래된 음부터 빠르게 페이드아웃.
- 사람이 건반을 직접 클릭했을 때도 같은 합성음.

## 5. 박자 정확도

- 연주회·라이브 연습의 음은 `setTimeout`이 아니라 **`AudioContext.currentTime` 기준 예약 재생.**
- lookahead 스케줄러: 25ms마다 깨어나서, 앞으로 100ms 안에 울릴 음을 미리 예약한다.
- 화면(초파리 점프, 건반 빛, 악보 띠 이동, 머릿속 패널)은 **예약된 소리 시각**을 기준으로 `requestAnimationFrame`에서 맞춘다. → 소리와 그림이 어긋나지 않게.
- 초파리 점프 애니메이션(150ms)은 음 시작 150ms 전에 시작해서, 건반에 닿는 순간 소리가 나게.
- 탭이 백그라운드로 가면 스케줄러가 멈출 수 있으니, 돌아왔을 때 진행 중인 연주회는 일시정지 상태로 표시.

## 6. 효과음 (전부 합성)

| 이름 | 언제 | 만드는 법 | 길이 | 버스 |
|---|---|---|---|---|
| 설탕 띵 | 정답 (라이브 연습만, 연주회 X) | 고음 사인 2개 (2093Hz, 2637Hz) 동시에, 작게, 빠른 감쇠 | 0.15s | sfx |
| 찌릿 | 오답 (라이브 연습만) | 화이트노이즈 → 밴드패스 1.5kHz + 사각파 60Hz 섞고 빠르게 진폭을 떨게 (20Hz). **크지 않게** | 0.25s | sfx |
| 날갯짓 윙 | 초파리가 건반 사이를 점프할 때 | 톱니파 220Hz 근처 + 트레몰로 30Hz, 아주 작게 | 0.15s | sfx |
| 박수 | 완주, 연주회 결과 ★★★ 이상 | 짧은 딸깍(노이즈 버스트 5ms, 하이패스 1kHz)을 랜덤 간격으로 수십~수백 개. 별 개수가 많을수록 더 많이, 더 길게 | 1.5 ~ 4s | crowd |
| 야유 "우~" | 퇴장, 연주회 ★ | 톱니파 120 ~ 160Hz 여러 개 (사람마다 다른 음) + 비브라토 5Hz + 로우패스 800Hz, 서서히 커졌다 작아짐 | 1.5s | crowd |
| 웅성웅성 | 연습 0회 연주회가 끝난 뒤, ★★ | 밴드패스 노이즈 (300 ~ 1,500Hz) + 느리고 불규칙한 진폭 변화 | 1.5s | crowd |
| 팡파레 | ★★★★★ (300회 마에스트로) | 피아노 합성음으로 도-미-솔-높은 도 아르페지오 + 마지막 화음 | 1s | music |
| 빨리 연습 완료 | ×10 / ×100 끝 | 짧은 상승음 (솔 → 높은 도) | 0.3s | sfx |
| 메트로놈 (선택) | 라이브 연습 박자 표시 | 1,000Hz 클릭 | 0.02s | sfx |

- 효과음은 항상 피아노보다 작게. 라이브 연습에서 설탕·찌릿 소리가 멜로디를 가리지 않게 볼륨을 낮게 잡는다.
- 연주회 도중에는 효과음 없이 피아노만 (곡이 잘 들리게). 반응 소리는 끝난 뒤 결과 카드와 함께.

## 7. 점검 체크리스트

- [ ] 설정 패널의 "정답 멜로디 듣기"로 곡이 정확히 반짝반짝 작은 별로 들림 (약 29초)
- [ ] 2박 음이 확실히 길게 들림
- [ ] 연습 0회 연주회가 확실히 엉망으로 들림
- [ ] 박수 + 피아노 + 팡파레가 겹쳐도 소리가 찢어지지 않음
- [ ] 빔프로젝터·노트북 스피커에서 찌릿 소리가 너무 시끄럽지 않음
- [ ] `M` 키 음소거 즉시 반영
- [ ] 첫 클릭 전에는 소리 안내가 보이고, 클릭 후 정상 재생
