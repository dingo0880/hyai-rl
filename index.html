ⓘ 이 데모는?

초파리 뇌의 버섯체를 흉내 낸 작은 신경망이 "반짝반짝 작은 별"을 연습해요.

선생님은 "맞았어(설탕 +1) / 틀렸어(찌릿 −1)"만 알려줘요. 정답 악보는 보여주지 않아요.

처음엔 아무 건반이나 치다가, 연습할수록 예상과 실제의 차이(도파민)로 조금씩 배워서 끝까지 치게 돼요. 이것이 강화학습이에요.

실제 초파리 뇌 전체가 아니라, 버섯체의 학습 구조를 본뜬 작은 모델이에요.

실제 초파리 뇌와의 대응

  • 투사뉴런 (PN, 22개) — 감각 입력: 지금 몇 소절 · 몇 번째 박인지 + 방금 들린 음
  • 케년세포 (KC, 2,000개) — 입력을 넓게 펼쳐서 상위 5%만 켜요 (APL 뉴런의 전체 억제를 흉내). 비슷한 상황도 서로 다른 패턴이 돼서 덜 헷갈려요.
  • 버섯체 출력 뉴런 (MBON, 8개) — 건반 8개 각각을 "치면 좋을 것 같은 정도"
  • 도파민 뉴런 (DAN) — 실제 보상 − 예상 보상 (예측오차). 켜진 케년세포 → 고른 건반 연결을 이만큼 바꿔요.

실제 초파리와 다른 점

  • 실제로는 도파민이 KC→MBON 시냅스를 주로 약하게 만들고, "다가가기"와 "피하기" MBON이 짝을 이뤄요. 이 데모는 이해하기 쉽게 +/− 값을 갖는 연결 하나로 단순화했어요.
  • 실제 초파리 한쪽 버섯체의 케년세포는 약 2,000개, 각 세포는 평균 7개 정도의 입력을 받아요. 개수는 비슷하게 맞췄지만 연결은 무작위로 만든 장난감이에요.
  • 실제 초파리는 피아노를 치지 않아요. 🙂

용어표

저작권

멜로디는 18세기 프랑스 민요 "Ah! vous dirai-je, maman"으로 저작권이 끝났어요. 계이름만 쓰고 가사는 넣지 않았어요. 소리는 전부 브라우저에서 합성하고, 초파리는 직접 그린 그림이에요.

처음부터 다시 할까요?

지금까지의 연습과 연습 일지가 모두 지워지고, 갓 태어난 초파리로 돌아가요.

📈 초파리가 점점 잘하게 되는 과정

성장 지도 — 행 = 연습 일지 단계, 열 = 42음. 금색 ✓ 맞음, 빨강 ✗ 틀림, 회색 = 아직 안 들어봄

학습 곡선 — 연습마다 몇 번째 음까지 갔나 (점 = 한 번, 선 = 10회 평균, 깃발 = 연습 일지)

놀람(도파민) 곡선 — 예상과 실제의 차이 = 학습 신호. 잘할수록 놀랄 일이 줄어요
